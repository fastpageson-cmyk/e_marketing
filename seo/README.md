# 불혹김치 네이버 스마트스토어 SEO

2026-2학기 한국외대 e마케팅 팀 프로젝트(팀 계치미)의 SEO 작업 폴더다. 김치 브랜드 **불혹김치**를 네이버 쇼핑 검색에 더 잘 노출시키는 것이 목표다.

최종 업데이트: 2026-10-30. 스마트스토어에는 아직 아무것도 적용하지 않았다.

## 한눈에 보기

| 항목 | 결론 | 자세한 문서 |
|---|---|---|
| 브랜드 | "불혹김치"를 상품명 맨 앞과 브랜드 칸에 쓴다 | `스마트스토어/상품명_추천.md` 근거 1 |
| 상품명 | 4개 상품마다 주력 키워드를 나눈다 (아래 표) | `스마트스토어/상품명_추천.md` |
| 상품 구조 | 썸네일이 준비되면 4개를 2개(소용량·대용량)로 합친다 | `스마트스토어/SEO_핸드오프.md` 2절 |

### 상품명 추천 (4개 그대로 둘 때)

| 상품 | 상품명 |
|---|---|
| 1kg | `불혹김치 국산 썰은배추김치 1kg 맛김치 소포장김치` |
| 2kg | `불혹김치 국산 썰은김치 2kg 김치찌개용김치 배추김치` |
| 5kg | `불혹김치 국산 배추김치 5kg 김장김치 포기김치` |
| 10kg | `불혹김치 국산 배추김치 10kg 포기김치 김장김치` |

2개로 합칠 때는 소용량 `불혹김치 국산 썰은배추김치 1kg 2kg 맛김치 소포장`, 대용량 `불혹김치 국산 배추김치 10kg 5kg 포기김치 김장김치`를 쓴다(대용량은 팀 확정 필요).

### 가격 표기 (즉시할인 10% 기준)

| 상품 | 판매가 | 할인가 | 배송비 |
|---|---|---|---|
| 1kg | 11,900원 | 10,710원 | 3,000원 |
| 2kg | 18,900원 | 17,010원 | 3,000원 |
| 5kg | 39,900원 | 35,910원 | 무료 |
| 10kg | 74,900원 | 67,410원 | 무료 |

"최대할인가"는 쿠폰까지 적용한 가격이라 로그인 여부와 쿠폰 수령 여부에 따라 보였다 안 보였다 한다. 누구에게나 같은 할인율과 취소선이 보이는 것은 즉시할인뿐이다.

## 어떻게 진행했나

1. **1차 키워드 조사** (`세부키워드/`)
   - 네이버 검색광고 키워드도구로 김치 165건, 계란 29건의 월 검색수를 받았다.
   - 아이템스카우트로 상품 수를 보고 경쟁강도(상품 수 ÷ 월 검색수)를 계산했다.
   - 결론: "국내산"보다 "국산", 대용량은 포기김치·배추김치 10kg, 소용량은 썰은배추김치·썰은김치.
2. **추가 키워드 조사** (`스마트스토어/키워드_추가조사.md`, `.csv`)
   - 연관 키워드를 더 뽑아 34개를 다시 측정했다.
   - 새로 찾은 것: 김치주문(경쟁강도 0.98), 배추김치 10kg(4.07), 김치찌개용김치(8.69).
   - 블로그 주제 후보: 김장시기(월 3,720), 김치보관법, 김치유통기한.
3. **현재 스토어 점검** (`스마트스토어/현재_가격.md`)
   - 10/30 상품 목록을 캡처했다. 4개 상품명이 중량만 다르고 썸네일도 같아 중복상품 위험이 크다.
   - 5kg·10kg에만 붙는 최대할인가가 흔들리는 문제를 기록했다.
4. **쇼핑 클릭 데이터로 재검증** (`도구/shopping_insight.py`)
   - 데이터랩 쇼핑인사이트로 식품 카테고리 안의 실제 쇼핑 클릭을 비교했다.
   - 배추김치가 포기김치보다 클릭이 많다(10kg 1.3~1.6배, 5kg 약 2배). 그래서 5kg·10kg 상품명 앞을 배추김치로 바꿨다.
   - 김장김치 클릭이 8월에서 10월 사이 약 4배로 늘었다.
   - 대용량은 40~50대가 73~75%, 썰은김치는 30대 비중이 25%로 높다.
5. **가격 표기 방안** (`스마트스토어/가격_표기_방안.md`)
   - 외부 자료(메이크샵 공지, 2026-07 네이버 가격 표시 개선 기사 등)로 최대할인가 계산 방식을 확인하고, 즉시할인 중심안을 만들었다.
6. **도구와 스킬 정리**
   - `도구/`: 월 검색수 스크립트, 쇼핑 클릭 스크립트, API 키 진단, 외부 도구 목록.
   - `skills/smartstore-seo/`: 이 조사 순서와 규칙을 Claude Code 스킬로 정리했다.

## 앞으로 할 일

### 팀 결정이 필요한 것
- [ ] 즉시할인 할인율(10% 임시)과 기간(~12/15 안)을 확정한다.
- [ ] 상품명을 언제 바꿀지, 4개 유지 후 2개로 합칠지 정한다.
- [ ] 대용량 통합 상품명(배추김치 앞 / 포기김치 앞)을 고른다.
- [ ] 태그 교체안을 확정한다.

### 스마트스토어에 적용할 것 (순서대로)
1. [ ] 3,000원 쿠폰을 끈다(혜택관리).
2. [ ] 4개 상품에 즉시할인을 건다.
3. [ ] 스토어찜 쿠폰 1,000원(최소 주문 10,000원)을 만든다.
4. [ ] 상품명과 태그를 바꾼다. 바꾼 날짜를 기록한다.
5. [ ] 조건부 무료배송 30,000원이 할인 전·후 중 어느 금액 기준인지 확인한다.
6. [ ] 로그아웃·로그인 상태 화면을 캡처해 `스마트스토어/이미지/`에 날짜를 붙여 저장한다.

### 그다음
- [ ] 썸네일 4장을 다르게 만든다(최소 소용량과 대용량은 달라야 한다). 준비되면 2개로 합친다.
- [ ] 합치기 전에 즉시할인이 옵션 추가금에도 붙는지 미리보기로 확인한다.
- [ ] 상품명 변경 1~2주 뒤 유입 키워드와 순위를 비교한다.
- [ ] 김장철 블로그 글(김장시기, 김치보관법)을 쓴다.

## 주의

- API 키 파일(`*.env`)은 `.gitignore`로 막혀 있다. 공개 저장소라 절대 커밋하지 않는다.
- 가격 표기 관련 근거는 대행사 글과 기사 같은 2차 자료다. 네이버 공식 공지와 다를 수 있다.
- 쇼핑인사이트 수치는 호출마다 최댓값을 100으로 둔 상대값이라 표끼리는 비교하지 않는다.
