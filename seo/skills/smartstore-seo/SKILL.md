# smartstore-seo

## 자료 위치 (e_marketing 저장소)

- `seo/스마트스토어/SEO_핸드오프.md`: 상품 구조, 확정안, 남은 일
- `seo/스마트스토어/키워드_추가조사.csv`: 지금까지 조사한 키워드 수치. 새로 조사하면 여기에 행을 추가한다.
- `seo/스마트스토어/상품명_추천.md`, `입력_체크리스트.md`, `현재_가격.md`
- `seo/도구/keyword_volume.py`: 월 검색수 조회
- `seo/세부키워드/`: 10월 세부키워드 발굴 결과(계란·김치)

## 키워드 조사 순서

1. 월 검색수를 받는다: `python3 seo/도구/keyword_volume.py 결과.csv 키워드...`
   - 연관키워드를 넓게 볼 때는 `--related`를 붙인다.
   - 결과의 5는 "10 미만"이라는 뜻이다.
2. 상품 수를 받는다: Claude in Chrome으로 itemscout.io/keyword에 들어간다(사용자 크롬, 카카오 로그인 상태).
   - 키워드를 띄어 써서 검색하고, 7초 기다린다.
   - 읽기: `document.body.innerText`에서 `상품수 … 한 달 검색수 … 경쟁강도 …` 구간을 정규식으로 뽑는다.
   - 상품 수가 "-"로 나오면 집계가 안 된 것이다. 판정 보류로 적는다.
3. 경쟁강도 = 상품 수 ÷ 월 검색수. 해석 기준은 다음과 같다.
   - 5 미만: 아주 좋음
   - 5~15: 상품명 주력 키워드 후보
   - 15~40: 보조 키워드
   - 40 넘음: 태그로만 쓰거나 쓰지 않는다
4. 네이버쇼핑 검색 페이지와 쇼핑 검색 API는 쓸 수 없다. 이유는 `seo/도구/README.md`에 있다.

## 상품명 규칙

- `브랜드(계치미) + 국산 + 주력 키워드 + 중량 + 보조 키워드` 순서로 쓴다. 50자 이내로 한다.
- "국내산"이 아니라 "국산"을 쓴다(검색량 1.4~3배). 원산지 칸에만 "국내산(경기도 용인)"을 넣는다.
- 다음은 넣지 않는다.
  - 같은 단어 반복
  - 쉼표를 포함한 특수문자
  - "무료배송", "최저가", "할인" 같은 홍보 문구
  - 다른 회사 브랜드(종가집, 비비고, 풀무원)
- 실제 상품 형태와 맞춘다. 썰은 김치에 "포기김치"를 쓰지 않는다.
- 같은 스토어 상품끼리는 주력 키워드와 썸네일을 다르게 한다. 중복상품 위험이 있다.
- 상품명을 바꾼 날짜를 기록하고 1~2주 뒤 유입 키워드로 평가한다. 자주 바꾸지 않는다.

## 태그 규칙

- 10개까지 넣고, 상품명에 들어간 단어는 뺀다.
- 태그사전에 없는 단어는 반영되지 않는다. 등록 화면 경고를 보고 교체한다.
- 검색이 거의 없는 단어(월 100 미만)보다는 경쟁강도가 낮은 단어를 우선한다(예: 김치주문 0.98).

## 하지 않는 것

- 스마트스토어센터 로그인과 상품 입력은 사용자가 직접 한다.
- API 키를 출력하거나 커밋하지 않는다. `*.env`는 `.gitignore`로 막혀 있다.
- 판매한 적 없는 가격을 정가로 써서 할인율을 부풀리는 안은 제안하지 않는다(표시광고법).
