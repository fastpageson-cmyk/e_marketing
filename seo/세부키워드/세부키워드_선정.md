# 계란·김치 세부키워드 선정 (동료 목록 194개와 중복 없음)

- 데이터: NAVER API HUB 검색어트렌드, 2025-10 ~ 2026-09 월 단위, PC+모바일
- 조회수 환산: 동료 목록의 실측값을 기준점으로 사용 (계란 = 동물복지계란 1,320 / 김치 = 포기김치10KG 2,620)
- 검증: 반숙계란 추정 1,688 vs 실측 1,690, 맛김치 추정 3,515 vs 실측 3,640 → 오차 4% 이내
- 조회수 = 2026-09 한 달 추정치. 괄호 안은 12개월 평균
- 상품수: 쇼핑검색 API 종료(2026-07-31)로 미조회. 최종 후보는 네이버쇼핑에서 직접 확인 필요

## 참고
- 김치는 11월(김장철)에 검색이 몰림. 12개월 평균이 9월 값보다 큰 키워드(김장김치, 섞박지, 김치10kg)는 10~11월 상품명·태그에 먼저 반영
- 성격(상업성/정보성) 표시는 키워드 문구를 보고 판단한 것이며, API 데이터가 아님
