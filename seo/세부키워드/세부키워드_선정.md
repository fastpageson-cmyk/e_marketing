# 계란·김치 세부키워드 (동료 목록 194개와 중복 없음)

- 세부키워드 기준: **월 조회수 300~5,000** (상품수 조건은 적용하지 않기로 함)
- 데이터: NAVER API HUB 검색어트렌드, 2025-10 ~ 2026-09 월 단위, PC+모바일
- 조회수 환산: 동료 목록 실측값을 기준점으로 사용 (계란 = 동물복지계란 1,320 / 김치 = 포기김치10KG 2,620)
- 검증: 반숙계란 추정 1,688 vs 실측 1,690, 맛김치 추정 3,515 vs 실측 3,640 → 오차 4% 이내
- 월 조회수 = 2026-09 추정치. 괄호 안은 12개월 평균
- 후보 515개를 조사함. 후보는 직접 작성했고(5차례 확장), 하나하나 데이터랩으로 검증함. 전체 결과: `세부키워드_결과.csv`
- 성격 표시는 키워드 문구를 보고 판단한 것이며, API 데이터가 아님. 상품명·태그에는 **상업성**을, 블로그·상세페이지 본문에는 정보성을 쓰는 것을 권장
