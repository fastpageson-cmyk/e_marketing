### 근거

1. **브랜드 "불혹김치"는 맨 앞에 그대로 둔다.**
   - 지금은 월 검색이 10회 미만이다. 그래서 넣어도 빼도 검색 유입은 거의 같다.
   - 그래도 넣는 쪽이 낫다. 네이버 권장 형식이 "브랜드 + 상품명"이고, 상품명의 브랜드가 브랜드 칸과 같아야 브랜드로 묶인다.
   - 오프라인 계란 판매, QR, 리뷰로 브랜드를 기억한 사람은 "불혹김치"로 검색한다. 그때 상품명에 브랜드가 있어야 바로 잡힌다.
   - 비용은 4자뿐이다. 모든 안이 50자 한도에 한참 못 미친다.
   - 뺀다면 대표 키워드 하나(예: 맛김치)를 더 넣을 자리가 생긴다. 하지만 상품명이 브랜드 없는 상품처럼 보인다.
2. **"국내산"을 "국산"으로 바꾼다.** 국산김치는 월 3,650회, 국내산김치는 2,590회다. 국산김치 10kg(3,200회)와 국내산김치 10kg(1,100회)는 거의 3배 차이가 난다. 원산지 칸에는 "국내산(경기도 용인)"을 그대로 둔다.
3. **", 1개"를 뺀다.** 검색되는 말이 아니고, 쉼표는 특수문자 감점 대상이다.
4. **소용량(1kg, 2kg)은 "포기김치"를 빼고 "썰은" 계열로 바꾼다.**
   - 실제 상품이 썰은 김치이므로, 이름이 실제 상품과 맞아야 한다.
   - 검색도 거의 없다. 포기김치 1kg는 월 50회, 포기김치 2kg는 120회뿐이다.
   - 경쟁은 썰은 계열이 더 약하다. 썰은배추김치는 9.66, 썰은김치는 12.97이다.
5. **1kg와 2kg은 주력 키워드를 나눈다.**
   - 1kg는 "썰은배추김치 + 맛김치 + 소포장"으로 1~2인 가구를 노린다.
   - 2kg는 "썰은김치 + 김치찌개용김치 + 배추김치"로 요리용 수요를 노린다.
   - 둘 다 "김치 1kg/2kg" 검색에도 걸린다. 띄어 쓴 단어 조합으로 매칭되기 때문이다.
6. **10kg는 "배추김치 10kg"를 앞에 둔다.**
   - 포기김치 10kg보다 검색은 1.9배 많고, 경쟁강도는 3분의 1(4.07 대 11.34)이다.
   - 쇼핑 클릭도 1.3~1.6배 많다(아래 쇼핑인사이트 표).
   - 포기김치와 김장김치를 뒤에 붙여 두 키워드도 같이 잡는다.
7. **5kg도 "배추김치 5kg"를 앞에 둔다.**
   - 쇼핑 클릭은 배추김치 5kg가 포기김치 5kg의 약 2배다. 포기김치 5kg는 경쟁강도도 72.75로 약하다.
   - 10kg와 너무 비슷해지지 않게 뒤쪽 순서는 "김장김치 포기김치"로 바꿨다.
   - 그래도 중량만 다른 두 상품이 비슷해 보이는 위험은 남는다. 2개로 합치면 해결된다.
8. **모두 50자 안에 들어간다.** 길이는 26~29자다. 같은 단어 반복이나 홍보 문구가 없다.

- **10kg:** 배추김치10kg와 김치10kg가 포기김치10kg보다 클릭이 많다. 상품명 순서를 바꾸는 근거가 된다.
- **김장김치:** 클릭이 8월에서 10월 사이 약 4배로 올랐다. 김장철이라 상품명 뒤쪽에 둔 김장김치가 11~12월에 더 중요해진다.
- **김장김치10kg:** 검색(월 400회)에 비해 쇼핑 클릭이 거의 없다. 상품명보다 블로그 주제로 쓴다.
- **김치주문:** 쇼핑 클릭도 많다. 태그로 넣는 근거가 된다.
- **썰은김치와 썰은배추김치:** 썰은김치 클릭이 1.3~2배 많다. 2kg 상품명 앞에 썰은김치를 둔 것과 맞는다. 썰은배추김치는 클릭이 꾸준히 오르고 있다.
- **구매층 (7~10월 클릭, 쇼핑인사이트 로그인 사용자 기준):**
  - 김치10kg와 맛김치는 40~50대가 73~75%다. 대용량 상세페이지 문구는 40~50대 가구에 맞춘다.
  - 썰은김치는 30대가 25%로, 다른 키워드(12%)보다 두 배 높다. 소용량 상세페이지는 30대와 1~2인 가구에 맞춘다.
  - 남성 비율이 56~66%로 나오는데, 실제로 먹는 사람이 아니라 클릭한 계정 기준이다.

### 같이 할 것

- [ ] 썸네일 4장을 다르게 만든다. 최소한 소용량(썰은 김치)과 대용량(포기·박스)은 달라야 한다. 상품명만 바꾸면 중복상품 위험이 남는다.
- [ ] 카테고리도 같이 맞춘다. 소용량은 맛김치·썰은김치 쪽, 대용량은 포기김치·배추김치 쪽 세부 카테고리를 고른다.
- [ ] 상품명을 바꾼 날짜를 기록한다. 1~2주 뒤 유입 키워드를 비교한다.

## 쇼핑 검색 API가 있으면 결론이 바뀌나

바뀌지 않는다. 네이버 쇼핑 검색 API의 `total`(검색 결과 상품 수)은 아이템스카우트가 보여 주는 "상품 수"와 같은 지표다. API로 받아도 경쟁강도 계산은 그대로다.

API가 있으면 좋아지는 점은 세 가지다.
- 아이템스카우트에서 집계가 안 된 키워드(배추김치 5kg, 김치 20kg)의 상품 수를 채울 수 있다.
- 상위 상품 100개의 상품명과 카테고리를 한 번에 받아, 카테고리를 맞추는 근거로 쓸 수 있다.
- 브라우저를 쓰지 않고 스크립트로 반복 조사할 수 있다.

API 키 문제는 `../도구/README.md`에 정리했다.
