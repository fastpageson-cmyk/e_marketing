# 스마트스토어 상품 입력 체크리스트 (김치 2개 상품)

스마트스토어센터 → 상품관리 → 상품 등록(또는 상품 조회/수정)의 칸 순서대로 적었다. 입력은 스토어 담당자가 직접 한다.
근거와 키워드 수치는 `SEO_핸드오프.md`, `키워드_추가조사.md`에 있다.

## 0. 입력 전에 할 것

- [ ] 기존에 중량별로 따로 올린 4개 상품의 상품번호, 리뷰 수, 판매 수를 적어 둔다.
- [ ] 리뷰가 가장 많은 기존 상품을 수정해서 새 상품으로 쓸지, 새로 등록할지 정한다. 수정해서 쓰면 리뷰와 판매 이력이 남는다.
- [ ] 남는 기존 상품은 삭제하지 말고 "판매중지"로 둔다. 리뷰 데이터가 남는다.
- [ ] 팀 확정이 필요한 3가지를 먼저 정한다: 대용량 상품명 안(아래 2번), 할인율과 기간, 바꿀 태그.
- [ ] 새 썸네일 사진을 준비한다. 소용량은 썰어 담은 사진, 대용량은 김치통이나 박스 사진이 필요하다.

## 1. 카테고리

- [ ] 두 상품 모두 식품 → 김치 계열로 넣는다. 소용량은 맛김치·썰은김치 쪽, 대용량은 포기김치·배추김치 쪽 세부 카테고리를 고른다.
- [ ] 정하기 전에 네이버쇼핑에서 "썰은배추김치", "포기김치 10kg"를 검색한다. 상위 상품이 쓰는 카테고리와 같게 맞춘다. 카테고리가 다르면 그 키워드 검색에서 불리하다.

## 2. 상품명

| 상품 | 입력값 | 글자 수 |
|---|---|---|
| 소용량 | `불혹김치 국산 썰은배추김치 1kg 2kg 맛김치 소포장` | 30자 |
| 대용량 (현재 확정안) | `불혹김치 국산 포기김치 10kg 5kg 김장김치 배추김치` | 31자 |
| 대용량 (대안, 팀 결정 필요) | `불혹김치 국산 배추김치 10kg 5kg 포기김치 김장김치` | 31자 |

- [ ] 상품명 맨 앞의 브랜드 "불혹김치"와 브랜드 칸 값이 같은지 확인한다.
- [ ] "무료배송", "최저가", "할인", 특수문자, 같은 단어 반복이 없는지 확인한다.
- [ ] 대안을 쓰는 이유: "배추김치 10kg"가 월 5,990회 검색되고 경쟁강도가 4.07이다. "포기김치 10kg"는 월 3,190회, 경쟁강도 11.34다.

## 3. 판매가와 즉시할인

옵션이 있는 상품은 "판매가 + 옵션가"로 값이 정해진다. 판매가는 가장 싼 옵션의 가격으로 넣는다.

| 상품 | 판매가 | 옵션 | 옵션가(추가금) | 최종 판매가 |
|---|---|---|---|---|
| 소용량 | 11,900원 | 1kg | 0원 | 11,900원 |
| | | 2kg | +7,000원 | 18,900원 |
| 대용량 | 39,900원 | 5kg | 0원 | 39,900원 |
| | | 10kg | +35,000원 | 74,900원 |

- 옵션가는 판매가의 -50%에서 +100% 사이여야 한다. 소용량은 +59%, 대용량은 +88%라서 둘 다 범위 안이다.
- [ ] **즉시할인이 어디까지 붙는지 확인한다.** 스마트스토어 즉시할인은 판매가에만 붙고 옵션가에는 붙지 않는 것으로 알려져 있다. 그렇다면 10%를 걸어도 결과는 아래 표처럼 된다.

| 옵션 | 핸드오프 표의 할인가 | 판매가에만 할인이 붙을 때 | 실제 할인율 |
|---|---|---|---|
| 1kg | 10,710원 | 10,710원 | 10% |
| 2kg | 17,010원 | 17,710원 | 약 6.3% |
| 5kg | 35,910원 | 35,910원 | 10% |
| 10kg | 67,410원 | 70,910원 | 약 5.3% |

- 이 계산은 즉시할인이 판매가에만 붙는다는 가정을 따랐다. 할인액은 판매가 기준으로 소용량 1,190원, 대용량 3,990원으로 고정되고, 옵션가는 그대로 더해진다.
- [ ] 저장하기 전에 등록 화면의 가격 미리보기나 상품 상세에서 2kg와 10kg 가격을 직접 확인한다.
- [ ] 옵션 가격까지 10% 할인이 붙지 않으면 셋 중 하나를 고른다.
  1. 옵션가를 할인 기간에만 낮춘다. 2kg는 +6,300원, 10kg는 +31,500원으로 넣는다. 할인이 끝나면 원래 옵션가로 되돌려야 한다.
  2. 할인 표기를 "1kg·5kg 10% 할인"으로 좁힌다.
  3. 중량마다 할인율이 다르다는 것을 받아들이고 상세페이지에 옵션별 가격을 적는다.
- [ ] 할인 기간: 12월 15일까지(임시값). 할인율도 팀 확정이 필요하다.
- [ ] 판매한 적 없는 가격을 정가로 만들어 할인율을 부풀리지 않는다. 판매가를 올려 할인을 거는 방식을 쓰면, 할인이 끝난 뒤 그 판매가로 실제로 팔아야 한다.
- [ ] 부가세: 김치는 면세 품목이다. 사업자 유형에 맞게 "면세상품"을 고른다.

## 4. 재고와 옵션

- [ ] 옵션 형태: 단독형, 옵션명은 "중량"으로 한다.
- [ ] 옵션값: 소용량은 `1kg`, `2kg`, 대용량은 `5kg`, `10kg`로 넣는다. 위 표의 옵션가도 같이 넣는다.
- [ ] 옵션별로 재고를 넣는다. 공급처에서 받을 수 있는 수량 안에서 넣는다.

## 5. 상품 이미지

- [ ] 대표 이미지: 소용량은 썰어 담은 사진, 대용량은 김치통이나 박스 사진. 두 상품의 썸네일이 겹치면 안 된다(중복상품 위험).
- [ ] 대표 이미지에는 글자, 테두리, "무료배송" 문구를 넣지 않는다.
- [ ] 추가 이미지 2번째 장에 무료배송 안내를 넣는다: `30,000원 이상 무료배송 · 5kg 이상 전 상품 무료배송`

## 6. 상세설명

- [ ] 첫 화면 배너에 무료배송 안내를 넣는다. 문구는 추가 이미지와 같다.
- [ ] 원산지 "국내산(경기도 용인)"을 앞쪽에 보이게 넣는다.
- [ ] 옵션별 가격과 kg당 가격을 표로 넣는다(배송비 포함 기준).

| 옵션 | kg당 가격(배송비 포함, 할인 전) |
|---|---|
| 1kg | 14,900원 |
| 2kg | 10,950원 |
| 5kg | 7,980원 |
| 10kg | 7,490원 |

- [ ] 상세페이지 HTML은 저장소 `frontend/index.html`, `frontend/option2.html` 중 팀이 정한 안을 쓴다.

## 7. 상품 주요정보

- [ ] 브랜드: `불혹김치`
- [ ] 제조사: 실제 제조사(공급처)를 넣는다. 브랜드 칸과 헷갈리지 않는다.
- [ ] 원산지: 국산 → `국내산(경기도 용인)`
- [ ] 상품 속성(맛, 형태, 중량 등이 나오면): 실제 상품과 같게 고른다. 속성 필터 검색에 잡힌다.
- [ ] 제조일자와 소비기한: 공급처 기준으로 넣는다.

## 8. 상품정보제공고시 (식품)

공급처 정보가 있어야 채울 수 있다. 빈칸이나 "상세페이지 참조"로 두지 않는다.

- [ ] 제품명, 식품의 유형(배추김치)
- [ ] 생산자와 소재지
- [ ] 제조연월일, 소비기한(또는 품질유지기한)
- [ ] 포장 단위별 내용물의 용량(중량)과 수량
- [ ] 원재료명과 함량(고춧가루 원산지 포함)
- [ ] 영양성분(표시 대상이면)
- [ ] 유전자변형식품 해당 여부
- [ ] 소비자 안전을 위한 주의사항(보관 온도, 발효로 포장이 부풀 수 있음 등)
- [ ] 소비자상담 전화번호

## 9. 배송

| 항목 | 소용량 | 대용량 |
|---|---|---|
| 배송비 | 조건부 무료: 3,000원, 30,000원 이상 무료 | 무료 |
| 묶음배송 | 같은 배송비 묶음 그룹 | 같은 그룹 |
| 제주·도서산간 추가 배송비 | 택배사 기준으로 설정 | 택배사 기준으로 설정 |

- [ ] 두 상품을 같은 묶음배송 그룹에 넣는다. 소용량과 대용량을 같이 사면 대용량 무료배송이 적용되는지 결제 화면에서 확인한다.
- [ ] 출고지, 반품지 주소와 택배사를 넣는다. 택배사 양식은 `[팀 계치 미 이프 유 캔](10-29~10-30) 택배사양식변환.xlsx`를 참고한다.
- [ ] 발송 예정일을 실제 공급처 출고 일정에 맞춘다. 늦게 보내면 판매자 등급이 떨어진다.

## 10. 반품과 교환

- [ ] 반품·교환 배송비를 넣는다.
- [ ] 신선식품이라 단순 변심 반품이 제한된다는 안내를 넣는다. 상품 하자나 오배송은 제외한다.

## 11. 구매와 혜택 조건

- [ ] 리뷰 포인트를 켠다. 텍스트 리뷰와 포토 리뷰에 차등을 둔다. 첫 리뷰 10~30개 확보용이다.
- [ ] 소용량에 복수구매 할인을 검토한다. 예: 2개 이상 구매 시 1,000원 할인.
- [ ] 혜택관리 → 스토어찜 쿠폰 1,000원을 만든다(상품 등록 화면이 아니라 따로 설정한다).

## 12. 검색 설정

태그는 상품명에 들어간 단어를 빼고 10개까지 넣는다. 저장할 때 "태그사전에 없는 태그"로 뜨는 것은 빼고 아래 교체 후보로 채운다.

| 상품 | 확정안 태그 | 교체 제안 (팀 결정) |
|---|---|---|
| 소용량 | 썰은김치, 배추김치, 국산김치, 김치1kg, 김치2kg, 자취김치, 소포장김치, 썬김치, 김치추천, 맛있는김치추천 | 자취김치(월 25회)를 김치주문으로, 썬김치(월 15회)를 김치찌개용김치로 바꾼다. |
| 대용량 | 국산김치10kg, 김장김치10kg, 포기김치, 국산포기김치, 김치10kg, 김치5kg, 배추김치5kg, 김치추천, 배추김치추천, 국산김치 | 포기김치(상품명과 겹침)를 김치주문으로, 배추김치추천을 배추김치10kg으로 바꾼다. 상품명 대안을 쓰면 배추김치10kg 대신 국산포기김치를 그대로 둔다. |

- [ ] 태그를 저장한 뒤 반영 여부를 표시해 둔다(반영됨 / 태그사전 미등록).
- [ ] Page Title과 Meta description은 상품명과 같은 키워드로 짧게 쓰거나 비워 둔다. 홍보 문구는 쓰지 않는다.

## 13. 등록 후 확인

- [ ] 상품 상세에서 옵션별 최종 가격과 할인가를 확인한다(3번 항목).
- [ ] 네이버쇼핑 검색 결과에 무료배송 표시가 붙는지 확인한다. 반영까지 하루쯤 걸릴 수 있다.
- [ ] 2~3일 뒤 "썰은배추김치", "포기김치 10kg", "배추김치 10kg", "김치주문"으로 검색한다. 노출 순위를 기록한다.
- [ ] 1~2주 간격으로 스토어 통계(유입 키워드, 클릭률, 전환율)를 보고 조정한다. 상품명은 자주 바꾸지 않는다.
