# 김치 키워드 추가 조사 (2026-10-30)

- 월 검색수: 네이버 검색광고 API 키워드도구 (최근 30일, PC+모바일, 10/30 조회). 표에서 5로 적힌 값은 "10 미만"이다.
- 상품 수: 아이템스카우트 키워드분석 화면 (기준일은 키워드마다 다르며 `키워드_추가조사.csv`에 적었다).
- 경쟁강도 = 상품 수 ÷ 월 검색수. 낮을수록 좋다.
- 원자료: `키워드_추가조사.csv`

## 재확인 결과

- 배추김치 5kg: 아이템스카우트에서 띄어 써도 상품 수가 집계되지 않는다. 판정 보류 상태로 둔다.
- 국내산김치 10kg: 월 검색수가 510회(10/28 조사)에서 1,100회로 늘었다. 그래도 상품명에는 "국산"을 쓴다(국산김치 10kg 3,200회).
- 포기김치 5kg(72.75), 국산배추김치(100.47)는 경쟁이 너무 세서 쓰지 않는다.

## 기존 확정안에서 바꿀 만한 것 (팀 확정 필요)

1. 대용량 상품명
   - 현재 안: `불혹김치 국산 포기김치 10kg 5kg 김장김치 배추김치`
   - 대안: `불혹김치 국산 배추김치 10kg 5kg 포기김치 김장김치`
   - 이유: "배추김치 10kg"가 "포기김치 10kg"보다 월 검색이 약 1.9배 많고, 경쟁강도는 3분의 1 수준이다. 단어 구성은 같고 순서만 바꾼다.
2. 소용량 태그: 자취김치(월 25회)와 썬김치(월 15회)는 검색이 거의 없다. 김치주문과 김치찌개용김치로 바꾼다.
3. 대용량 태그
   - "포기김치"는 상품명에 이미 들어 있어서 태그 규칙에 어긋난다. 김치주문으로 바꾼다.
   - 배추김치추천(45.74)이나 국산포기김치(월 290회)는 배추김치10kg으로 바꾼다. 대안 상품명을 채택하면 배추김치10kg은 상품명에 들어가므로 이 교체는 하지 않는다.
